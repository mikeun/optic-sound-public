# Contributing to Optic Sound

Thank you for your interest in Optic Sound and the **"Agent Reconstruction Manual"**.

As this is a reference project designed to support the book, the following guidelines apply to contributions:

## 1. Reference Implementation
This repository is primarily a living example of the concepts taught in the manual. As such, the core architecture is maintained to stay in sync with the book's chapters.

## 2. Feedback & Issues
- **Bug Reports:** If you find a bug that prevents the project from running as described in the book, please open an issue.
- **Hardware Compatibility:** If you have successfully adapted this project to different hardware (e.g., a different DAC or USB Turntable), we would love to hear about it in the GitHub Discussions or as an issue tagged `Hardware`.

## 3. Pull Requests
Since this is a proprietary reference project, large architectural changes via Pull Requests are generally not accepted unless they fix a critical bug. We encourage you to **fork** the repository and experiment with your own hardware-specific variations!

## 4. Proprietary Notice
Please remember that this project is **Proprietary (All Rights Reserved)**. By submitting a Pull Request or feedback, you agree that your contributions may be incorporated into the project or the book without additional compensation, while the overall copyright remains with Michael Untershlak.
